# kosatsu repository guidance

Keep EDN canonical and external JSON under `wire/`. Preserve attribution,
multi-source provenance, non-adjudication, delisting history, no scoring, no PII,
passive ingest, and dry-run publication gates. Do not restore former root paths,
Python twins, Go/TinyGo, wasm, or shell runners. Verify with `bb test`, format and
artifact audits, and `git diff --check`.
